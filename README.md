# Z-City
Z-City is a GMod addon which modifies character damage and controls. Z-City also comes with its own weapon base and a gamemode

ANARCHY is a Z-City fork that modifies Z-City in a way to make it more darker and more realistic

This Fork under the account "chadratt" is the first version of ANARCHY and is the only version being officially maintained
